# Промежуточный результат сопоставления

`competitor_matches.xlsx`: 1518 исходных строк, 34 связки для 33 артикулов, 210 уникальных ссылок в частичной базе конкурентов. Проверка всех строк выполнена только против этой базы, а не против всех товаров интернета.

25 связок по названию модели/цвета/размера (без сверки EAN), 6 связок с другой фасовкой, 3 неподтверждённых кандидата. Фотографии не сравнивались. Совпадения по EAN не установлены. Оставшиеся 1485 строк нуждаются в дальнейшем поиске; отсутствие связки не означает отсутствие товара у конкурентов.

Генератор: `python scripts/build_competitor_matches.py /path/to/source.csv` (зависимости: openpyxl, Unidecode). Исходный CSV не публикуется из-за сведений о поставщиках. Файл `competitors.xlsx` в корне — предыдущая версия базы ссылок, вход для генератора.
