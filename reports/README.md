# Промежуточный результат сопоставления

`competitor_matches.xlsx`: 1518 исходных строк, 61 связка для 60 артикулов, 237 уникальных ссылок в частичной базе конкурентов. Проверка всех строк выполнена только против этой базы, а не против всех товаров интернета.

53 связки по названию модели/цвета/размера (без сверки EAN), 6 связок с другой фасовкой, 2 неподтверждённых кандидата. Фотографии не сравнивались. Совпадения по EAN не установлены. Оставшиеся 1458 строк нуждаются в дальнейшем поиске; отсутствие связки не означает отсутствие товара у конкурентов.

## Последнее расширение

Добавлены 27 ранее не охваченных артикулов: 20 CE40/CE33, 4 LITOCHROM LUXURY EVO LLE, 3 позиции CS25 (два исходных артикула прозрачной затирки оставлены отдельно). Добавлена ещё одна ссылка на K80 для уже охваченного артикула. Для Аккорда дымчатого тёмного удалена неправильная связка с серым тёмным 9015, найдена карточка 9028.

Новые карточки и цены считаны из `https://999111.ru/catalog/zatirka?limit=200`, `https://999111.ru/catalog/klei?limit=100` и `https://apexdv.ru/collections/534-akkord` (фрагмент 1). Дата сбора 10.11.2026. Наличие и цены требуют проверки перед покупкой. LITOCHROM EVO без LUXURY не приравнивается к LITOCHROM LUXURY EVO только по коду цвета.

Генератор: `python scripts/build_competitor_matches.py /path/to/source.csv` (зависимости: openpyxl, Unidecode). Дополнительные проверенные по каталогу связки сохранены в `additional_matches.json`. Исходный CSV не публикуется из-за сведений о поставщиках. Файл `competitors.xlsx` в корне — предыдущая версия базы ссылок, вход для генератора.
