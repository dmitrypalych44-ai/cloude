# Сопоставление ассортимента: текущий результат

`competitor_matches.xlsx`: **107 уникальные связки «исходный артикул → карточка конкурента» для 81 исходных артикулов**. Всего 1518 исходных строк и 278 уникальных ссылок в частичной базе. Несколько карточек разных продавцов или фасовок одного товара считаются разными связками, но не увеличивают число охваченных исходных артикулов.

Разбивка 107 связок:
- 64 — совпадение модели/цвета/размера по описанию, EAN не сверён;
- 40 — та же модель/линейка и цвет, но другая фасовка;
- 1 — K77 EVO C2 TE S1 вместо исходного K77 C2TE S1, версия рецептуры требует проверки;
- 2 — неподтверждённые кандидаты по характеристикам плитки.

Таким образом, 105 связок по модели/линейке (включая другую фасовку и версию EVO) и 2 дополнительных кандидата. Это **не 107 точных совпадения и не 107 разных исходных артикула**. Фотографии не сравнивались, совпадения EAN не установлены. По оставшимся 1437 исходным строкам нужен дальнейший поиск.

## Ссылки Лемана ПРО рядом с конкурентами

На листе «Соответствия» столбец F — ссылка конкурента, G — ссылка Лемана ПРО, H — тип ссылки ЛП. Ссылки ЛП также добавлены на лист всех 1518 исходных позиций.

Найдено 12 прямых карточек ЛП по поисковой выдаче с совпадением исходного артикула в URL. Из них 8 относятся к артикулам с конкурентами (14 строк соответствий). Для остальных 93 строк соответствий сформирован региональный поиск по артикулу, **не прямая карточка**; это явно отмечено. Сформированные адреса поиска и их выдача не проверены. Каталог Владивостока при прямом чтении вернул HTTP 403. Найденные прямые карточки могут относиться к другим регионам: их адреса не подменялись на владивостокские, цены из этих регионов не использовались.

Маппинг прямых адресов: `lemanapro_links.json`. Все адреса взяты из результатов поиска, а не придуманы из названий.

В этом расширении добавлены 3 связки для 3 новых артикулов: Темари белый матовый 84612978 (цена конкурента за м², исходный учёт за лист — не сравнивать напрямую), комплект Litolevel 50 шт 85371454, стойка-основание Litolevel 82800605 с другой фасовкой 250 вместо 50 шт. ## Воспроизведение

`python scripts/build_competitor_matches.py /path/to/source.csv` (зависимости: openpyxl, Unidecode). Файл `competitors.xlsx` в корне — предыдущая база ссылок, вход генератора. Исходный CSV не публикуется из-за сведений о поставщиках. Все 1518 строк проверены только против собранной частичной базы, не против всего интернета. Отсутствие связки не доказывает отсутствия товара у конкурентов.
