# Сравнение с одинаковой фасовкой

`competitor_matches.xlsx` теперь применяет строгое правило: на лист «Соответствия» попадают только одинаковые масса, объём или количество в упаковке, извлечённые из исходного CSV ЛП и названий товаров конкурентов.

## Результат проверки

- 110 собранных связок всего, включая 3 новые;
- **56 связок для 49 исходных артикулов** с одинаковой фасовкой по описаниям;
- **40 связок с разной фасовкой** исключены из основной таблицы;
- **14 связок с неподтверждённой упаковкой** также вынесены на лист «Исключено и проверить»;
- все 1518 исходных строк сохранены на отдельном листе; ссылки конкурентов в нём теперь включают только пары с одинаковой фасовкой;
- база содержит 281 уникальную карточку конкурентов, далеко не полные каталоги.

В столбцах P–R показаны фасовка ЛП, фасовка конкурента и результат проверки. F и G — соседние ссылки конкурента и поиска ЛП **только во Владивостоке**.

**Проверка выполнена по вашему CSV ЛП, а не по актуальным карточкам ЛП.** Сайт Владивостока возвращал 403; региональные наличие, цены и актуальная упаковка ЛП не подтверждены. Одинаковая фасовка сама по себе не доказывает совпадение EAN, рецептуры или модели. Статусы модели и замечания сохранены отдельно; K77 EVO требует проверки версии. Фото не сравнивались.

## Правила

Масса сравнивается с массой, жидкий объём с объёмом, количество с количеством. Допустимы только преобразования г↔кг и мл↔л. Кг не приравниваются к литрам, масса брутто не подменяет нетто. Дробные значения 2 и 2,5 не равны. Обозначения CE33/2 и CE40/2 исходного файла разобраны как 2 кг; CL51/5 без единицы не считается доказательством 5 кг. Несколько разных значений в одном названии приводят к статусу «не подтверждено».

Плитка с совпадающим форматом, но неизвестной площадью/количеством в коробке конкурента больше не включена в основную таблицу. Площадь коробки ЛП (где есть в CSV) показана, площадь одной плитки не подменяет площадь коробки. Для мозаики исходное «шт» без явной единицы продажи конкурента также недостаточно. Пересчёт цены за кг не используется для обхода требования об одинаковой фасовке.

## Воспроизведение

`python scripts/build_competitor_matches.py /path/to/source.csv` (openpyxl, Unidecode). Логика проверки упаковки: `scripts/package_check.py`. Тесты: `PYTHONPATH=.cache/report-libs python -m unittest discover -s tests` (либо обычный Python с установленными зависимостями).

Исходный CSV не публикуется из-за сведений о поставщиках. Файл `competitors.xlsx` в корне — историческая база ссылок, вход генератора, **не текущий итоговый отчёт**. `lemanapro_links.json` — исторический материал других регионов; генератор его не использует. Отсутствие пары в основной таблице не означает отсутствия подходящего товара на рынке. Поиск не завершён.
