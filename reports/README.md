# Сравнение с магазинами Владивостока — без досок объявлений

Текущий файл: `competitor_matches.xlsx`. По требованию пользователя удалены **все предложения FarPost**, в том числе опубликованные от имени магазинов. Из каталога также убран агрегатор market.iprim.ru. Переименование продавца без замены URL не использовалось.

## Текущий результат

- **92 предложения для 78 уникальных исходных артикулов** с одинаковой фасовкой по описаниям;
- 55 пар на листе «Исключено и проверить»: 40 с другой фасовкой и 15 с неподтверждённой упаковкой;
- 147 пар всего, 291 карточка собственного сайта магазина в каталоге источников;
- все 1518 строк исходного списка сохранены;
- в F и G соседствуют ссылка конкурента и поиск ЛП исключительно во Владивостоке;
- лист «Замена источников»: 71 артикул, ранее имевший предложения на удалённой площадке; 4 теперь имеют собственный сайт магазина, для 67 подтверждённая замена пока не найдена.

**Предыдущие 142 артикула / 157 предложений больше не являются текущим результатом.** Из основной таблицы удалены 79 предложений FarPost. После этого оставалось 78 предложений собственных магазинов, затем добавлены 3 замены UNIS с сайта РЕЗЕРВ-СТРОЙ, промежуточный итог — 81; последнее расширение довело число до 92. У одной из затронутых позиций уже была ссылка собственного магазина.

## Последнее расширение после удаления досок объявлений

Добавлено 11 предложений собственных магазинов: 8 LUXURY EVO/LLE 2 кг в Красном Мамонте, CM17 Super Flex 25 кг в Дюне и 2 металлизированные добавки Основит XE1 0,13 кг (золото/серебро) в Дюне. Только две добавки увеличивают охват: 76 → 78 артикулов. Дополнительные предложения уже известных артикулов не считались новыми артикулами. Каталог вырос на 10 уникальных URL: оба цвета добавки размещены в одной карточке.

**Серебро 0,13 кг отсутствует в наличии** по таблице вариантов; его 1200 руб. — каталожная, а не подтверждённая текущая цена покупки. Золото 1310 руб., доступность конкретного цвета нужно уточнить; общий остаток карточки 1 шт. указан на Нейбута, 85Б. Масса 0,13 кг взята из заголовка, а не из ошибочного логистического поля «Вес: 0 кг». Исходные коды 014/2 и 014/4 в магазине не показаны: сопоставлены назначение, цвет и масса, EAN не подтверждён.

У ряда страниц Дюны старый URL не соответствует текущему товару. Добавка XE1 находится по URL очистителя SE1 P; CM17 — по URL CM11. Внесено текущее название из тела страницы, а не предположение по URL. SE1 P по такой ссылке не засчитан. CE40 1 кг не заменил исходные 2 кг, Kerateks не засчитан как тот же Основит. FDPMASTER отвергнут по географии: магазин в Московской области.

## Замены и проверенные альтернативы

На собственном сайте `reserv-stroy.ru` найдены UNIS 2000 25 кг (575 руб.), UNIS Гранит 25 кг DIY (964 руб.), UNIS Плюс 25 кг (790 руб.). Названия и упаковки прочитаны в каталоге UNIS. Класс клея, EAN и складской остаток требуют дополнительной сверки; цены не являются подтверждённым предложением продавца.

PLITONIT EasyFill антрацит 2 кг (3075 руб.) найден там же, но оставлен в проверке: исходное «антрацит - 2» не содержит единицы массы. РЕЗЕРВ-СТРОЙ GM-45 25 кг **не признан заменой**: в прямой карточке класс C0T, в исходнике C1. Terrapaste 1/5/20 кг не заменяет исходные 3,5/15 кг. Очиститель GEL EP 1 л в Красном Мамонте не заменяет 0,5 л. Доставку из другого региона без подтверждённого местного магазина не принимали за наличие во Владивостоке.

В основных соответствиях теперь только сайты «Помощник», «Красный Мамонт», «РЕЗЕРВ-СТРОЙ» и «Дюна». В каталоге кандидатов также остаются собственные сайты АПЕКС, Жаба-дискаунт и региональный каталог Сантехника.ру; включение в каталог само по себе не означает подтверждённого совпадения.

## Правила качества

`source_policy.py` разрешает только явно проверенные домены собственных магазинов; новый магазин нужно проверить и добавить в список разрешённых. Доски объявлений, агрегаторы и маркетплейсы не принимаются. Это правило применяется и при чтении исторической базы, и при добавлении новых карточек. Тест проверяет весь Excel на отсутствие ссылок удалённых площадок.

Масса сравнивается с массой, объём с объёмом, количество с количеством. Допустимы г↔кг, мл↔л; кг не приравниваются к литрам. Нельзя подменять площадь упаковки площадью одной плитки или пересчитывать другую фасовку для обхода требования. Значения упаковки и результат сравнения показаны в P–R. CE33/2 и CE40/2 исходного файла распознаются как 2 кг; CL51/5 без единицы массы не трактуется как 5 кг. Разделительная запятая после слова в записи «STONE,1кг» отделяется от десятичной запятой «0,5кг».

**Источником фасовки ЛП остаётся предоставленный CSV**, а не актуальная карточка магазина: сайт Владивостока возвращал HTTP 403. Текущие цены, наличие и упаковка ЛП не подтверждены. Совпадение фасовки не доказывает EAN, рецептуру, техническую идентичность или визуальное сходство. Фото не сравнивались; оговорки по моделям сохранены в каждой строке. Поиск замен не завершён, прежний рубеж более 100 артикулов без досок объявлений пока не восстановлен.

## Воспроизведение

`python scripts/build_competitor_matches.py /path/to/source.csv` (openpyxl, Unidecode).

`PYTHONPATH=.cache/report-libs python -m unittest discover -s tests`

Исходный CSV с данными поставщиков не публикуется. `competitors.xlsx` в корне — исторический входной файл, **не итоговый отчёт**: запрещённые источники из него отфильтровываются. `additional_matches.json` содержит только действующие записи собственных магазинов. `store_replacement_audit.json` хранит артикулы, затронутые удалением, без ссылок досок объявлений. `search_round_log.md` — исторический журнал; старые результаты до изменения правил не отражают текущие цифры.
