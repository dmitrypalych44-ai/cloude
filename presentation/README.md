# Стратегия Владивосток 2027 — читаемая пересборка презентации

Два варианта одной и той же презентации (49 слайдов, структура и данные исходника сохранены):
увеличены кегли, освобождено «воздушное» пространство, выровнена сетка, убраны наложения
плашек на текст и обрезанные строки.

## Готовые файлы

| Файл | Стиль | Что внутри |
|---|---|---|
| `out/strategiya-2027-classic.pdf` | **Стиль 1 · «Классика Лемана ПРО»** | Светлый фон, фирменный жёлтый и графит, воздушные карточки с мягкими тенями, то же визуальное семейство, что у исходника — но крупнее и чище |
| `out/strategiya-2027-3d.pdf` | **Стиль 2 · «3D-дизайн»** | Тёмная сцена, объёмные карточки с подсветкой и бликами, неоновый жёлтый акцент, 3D-пол с сеткой, заголовки в широком геометрическом шрифте |

PDF-страницы — 960×540 pt (16:9). Текст векторный, поиск и копирование работают, шрифты
встроены, печать на любом масштабе без потери качества.

| Файл | Формат | Для чего |
|---|---|---|
| `out/strategiya-2027-classic.pptx` | PowerPoint 16:9 | **редактируемая версия** светлого стиля: 49 слайдов, ~3 500 нативных объектов |
| `out/strategiya-2027-3d.pptx` | PowerPoint 16:9 | **редактируемая версия** 3D-стиля: 49 слайдов, ~3 600 нативных объектов |

В PPTX нет «страниц-картинок»: каждый текст — отдельный текстовый блок (правится двойным
щелчком), каждая карточка/плашка — автофигура с заливкой, обводкой и тенью, фотографии
вставлены как изображения с кадрированием и скруглением. Шрифт — Arial (жирный для
заголовков и цифр): он есть на любом ПК и в PowerPoint, а метрики сцены сняты
с Arial-совместимого Arimo, поэтому строки не «расползаются» и не переносятся.

Пересобрать PPTX из той же вёрстки: `npm run pptx` (нужен `python3` с `python-pptx`).

## Что изменилось по читаемости

- **Кегли.** Основной текст: было 6,4–8,2 pt → стало 9,4–12 pt; заголовки 23–34 pt;
  крупные цифры KPI 17–30 pt. Самые мелкие подписи — не меньше 7,8 pt (было 5–6 pt).
- **Сетка.** Единые поля 56 pt, одинаковая ширина карточек и зазоры, шапка слайда
  пересобрана: кикер → заголовок в 1–2 строки → подзаголовок, без наложений и пустых полос.
- **Плотные слайды переверстаны, а не сжаты.** Там, где у исходника 8–10 блоков,
  блоки перегруппированы в 2–4 колонки с короткими тезисами — все цифры и формулировки сохранены.
- **Авто-подгон.** Каждая подпись проверяется на переполнение: если текст не влезает,
  он аккуратно уменьшается (в разумных пределах), а сборка в терминале предупреждает о проблеме.

Состав слайдов повторяет исходник 1:1 (включая разделители и финальный слайд), поэтому
презентацию можно листать параллельно с оригиналом.

## Структура проекта

```
presentation/
├── build.js          # сборка PDF (+PNG-превью с флагом --png)
├── lib.js            # палитры, две темы, примитивы рисования, типографика, авто-подгон
├── lib-ui.js         # блоки вёрстки: KPI, карточки, таблицы, шаги, полосы-выводы
├── slides-1..5.js    # слайды 1–49 (по блокам презентации)
├── assets/
│   ├── fonts/        # Onest (текст) + Unbounded (акцентный шрифт 3D-темы)
│   └── img/          # логотип (тёмный/светлый), фото моста, магазина, команды
├── export-scene.js   # выгрузка сцены каждого слайда в JSON (для PPTX)
├── scene2pptx.py     # JSON → PPTX: нативные фигуры, текст, градиенты, тени
└── out/              # результат: 2 PDF + 2 PPTX + PNG-превью
```

## Пересборка

```bash
cd presentation
npm install          # нужен только @napi-rs/canvas
npm run build        # оба PDF → out/
npm run png          # плюс PNG всех слайдов → out/png-classic, out/png-3d
```

Правки контента — в `slides-*.js`: каждый слайд — функция `(ctx, theme) => {…}`, которая
одинаково работает в обеих темах (`theme.dark` переключает светлый/тёмный стиль).
